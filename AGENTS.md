# Working in this repository

Read README.md for the product scope and CONTRIBUTING.md for the issue, branch and review workflow. Keep proposed catalogue entries labelled as planned until their examples run.

When pairing with Youssef, explain a new pattern and the problem it solves before using it. For core React and TypeScript work, agree on the expected behaviour, let Youssef write the implementation, then review it with concrete feedback.

Before each commit, walk through the staged changes and wait for Youssef to explain them back in his own words. Use his verified Git identity and plain-English Conventional Commit messages. Preserve actual authorship and timestamps. Leave out automated attribution trailers and generator notices.
