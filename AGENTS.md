# Working in this repository

Read README.md for the product scope and CONTRIBUTING.md for the issue, branch and review workflow. Keep proposed catalogue entries labelled as planned until their examples run.

When pairing with Youssef, explain a new pattern and the problem it solves before using it. Implement requested code changes directly, including core React and TypeScript work.

Use Youssef’s verified Git identity and plain-English Conventional Commit messages. Preserve actual authorship and timestamps. Leave out automated attribution trailers and generator notices.

Follow the branch and commit naming conventions in CONTRIBUTING.md. Choose names that describe the feature, bug or document a maintainer will look for in Git history.
