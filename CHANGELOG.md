# Changelog

## Unreleased

- Added a source ZIP to every published entry, with its usage guide, requirements and MIT license.
- Added keyboard search on Browse and Entry. Ctrl+K or Cmd+K opens it, the arrow keys move between matches, Enter selects one and Escape returns focus.
- Published the same search dialog as the seventh entry, with a standalone React example.

- Added shareable catalogue search and category filters with empty results and reset.
- Added a copy-code component with clipboard confirmation and keyboard-accessible failure feedback.
- Added reusable examples in Pages, Utilities, Modules and AI tools, with source and verification instructions.
- Added German and Arabic catalogue interfaces, including RTL layout and persisted language selection.
- Added a Docker preview and browser regression checks.
