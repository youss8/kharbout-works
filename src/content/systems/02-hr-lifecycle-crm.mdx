<h2 id="architecture">Architectural approach</h2>

A multi-branch, bilingual (LTR/RTL) Human Capital platform covering the full employee lifecycle—org structure, employee records, contracts and amendments, leave pricing, attendance, and offboarding—where every step is a state machine scoped to branch and reporting line, payroll-sensitive columns are encrypted under a dedicated key, and signed PDFs render directly from the same templates shown in the UI.

Server-driven TALL stack with dedicated Form objects and single-purpose Services (`LeaveRequestPricing`, `LeaveDecisionAuthority`, `ContractAmendmentService`, `MonthWorkflow`); trigger-keyed explicit state machines; shared branch/reporting-line scopes (`scopeInCity`, `scopeVisibleTo`) driving both UI dropdowns and validation; observer-maintained headcount counters under row locks; notification outbox + atomic delivery ledger; ordered nightly contract lifecycle chain (`apply amendments → deactivate → auto-renew → track renewals → deactivate departed staff`).

**Stack** · PHP ^8.5, Laravel 13 (`bootstrap/app.php` architecture), Livewire 4, Volt, Flux 2, Alpine.js, Tailwind CSS v4 (`@theme`), Flowbite 3, MySQL (SQLite `:memory:` for tests), Laravel Reverb WebSockets, Chart.js 4, amCharts 5, SortableJS, Spatie Permission / ActivityLog / MediaLibrary / Browsershot (Puppeteer PDF), Maatwebsite Excel, `laravel-localization` (EN/AR RTL), `livewire-tables`, Web Push, ClamAV, ZKTeco ADMS biometric device ingest + LAN agent, PHPUnit 12, Laravel Pint.

<h2 id="modeling">Hardest data-modeling problems</h2>


### 1 · Immutable Signed Contracts (`asSigned()` Amendments)

Live contract holds current terms while amendments store allow-listed before/after JSON snapshots; pay tiers stay outside JSON in dedicated-key encrypted columns; `asSigned()` reconstructs original signed terms from Amendment 1's `before`; applying refuses if live row drifted (optimistic concurrency); weekly integrity job checks chain continuity.

### 2 · Deterministic Leave Balance Engine (`quote()`)

Single stateless service powers preview, validation, pending reservations, approval deductions, and calendars. Passes weekend explicitly (zero global worker state), handles seniority accruals, same-calendar-year carryover from true predecessor (`COALESCE(terminated_at, end_date)`), preserves remaining days via `amendment_offset` when daily hours change, isolates overtime credits so recalculations never wipe them, and enforces probation caps & eligibility rules.

### 3 · Dual Reporting Hierarchy & Concurrency Safety

`Position` self-references twice (`direct_manager_id` solid line + `tech_manager_id` dotted line), driving org charts, manager visibility, leave authority escalation when a manager is on leave, and ~133 `lockForUpdate` sites with documented lock ordering (`request`, then `balance`).

<h2 id="permissions">Roles and enforcement</h2>

| Role | Scope |
| --- | --- |
| Platform Admin | Administers the system. An explicit deny-list blocks salary access. |
| Head-Office HR | Handles organization-wide HR operations. |
| Regional HR | Access follows position, site and branch across five regional branches. |
| Executive / General Manager | Reads across the organization and decides requests in their own reporting line. |
| Manager | Acts on direct reports. |
| Employee | Manages their own records and requests. |
| Person-scoped grant | Attaches to an individual and cannot be attached to a role. |

### Enforcement layers

- One active role at a time (context switching)
- per-action Livewire permission middleware preventing forged wire calls
- 29 record policies with branch/line scopes
- single shared scope for dropdowns & validation
- dedicated encryption key for pay tiers (cast refuses to overwrite undecryptable values + key-health CLI check)
- Spatie audit log on 29 models + delivery ledger + HR-seen tracking
- ~133 `lockForUpdate` sites
- SHA-256 device agent keys + registered serial-only biometric ingest.

### Modules

Employees (completeness, self-proposed profile changes, onboarding/renewal/offboarding journeys, probation reviews, critical-position alerts, dual-line org chart); Contracts (row-locked capacity guard, T-30/21/14/7 atomic expiry alerts, chunked auto-renewal, future-dated amendments, headless-Chrome file-based PDF rendering); Leave Management (pure `quote()`, eligibility rules, two-tier Manager → HR review with transactional send-back refund, team overlap warnings, stand-in nomination); Attendance (legacy Excel 5 binary parser, idempotent punch storage on `device_no + minute`, explicit human decision on 0/1-punch days with `DRAFT` watermark, `Confirm → Approve → Lock → Overtime-to-Leave Credit → Reopen`); Cross-Cutting (Unified Work Inbox, draggable 12-col lazy-mounted dashboard grid, notification outbox, Reverb chat).
