Keyboard shortcut label

Show people which keys to press beside the command they want to use.

Requirements
HTML and CSS
Usage
Place the key combination beside the command it triggers. Match the label to the shortcut your application supports.
Quick check
Read the command and keys at a narrow screen width. Both should stay legible when the text wraps.
