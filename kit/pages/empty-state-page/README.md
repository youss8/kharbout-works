# Empty search results

Open `index.html` in a browser with JavaScript enabled. The HTML file contains the markup, styles and script.

The reading list opens with a search that matches no title. Tab to **Clear search** and press Enter. All three titles should reappear and the search field should have focus. Type a word from a title to narrow the list again.

Replace the three list items in the HTML with your own titles. The script matches the text content of each item.
