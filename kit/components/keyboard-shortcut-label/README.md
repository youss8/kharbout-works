# Keyboard shortcut label

Open `index.html` in a browser. The page uses HTML and CSS and runs without a build step.

Copy the `.command` element beside a command in your application and link `shortcut.css` from that page. Replace “Open search” and the contents of the two `kbd` elements with your command and keys. The host application handles the shortcut.

Narrow the page until the key group wraps to a new line. The keys should stay together. Set `dir="rtl"` on the containing page to check that the command follows the reading direction while the keys keep their order.
